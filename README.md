## 🚀 Features

### ✅ Core Functionality

* Add tasks with date, time, and category
* Delete tasks
* Mark tasks as completed ✔️
* Auto save & load tasks

---

### 🧠 Smart AI Logic

* Auto priority detection:

  * High → exam, deadline, urgent
  * Medium → study, project
  * Low → others

---

### 🎨 UI & Experience

* Animated background
* Hover effects
* Flash animation
* Dark mode 🌙

---

### 🔔 Productivity Tools

* Reminder system
* Task progress dashboard 📊

---

## 🖥️ Tech Stack

* Python

* Datetime

## ⚙️ Installation

```bash
git clone https://github.com/your-username/smart-ai-todo-app.git
cd smart-ai-todo-app
pip install matplotlib
python main.py
```

## 🧠 How It Works

* Tasks are stored in `tasks.txt`
* Auto load on start
* Auto save on change
* Reminder checks every minute
